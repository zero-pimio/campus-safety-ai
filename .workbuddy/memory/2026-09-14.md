### 项目本质
不是"训练万能 YOLO"，而是 contract-first 的视频事件链：
FramePacket → Detections → Track → BehaviorObservation → EventRecord → SQLite Outbox → Destination。
三个深模块：`core/perception.detect`、`core/event_analysis.advance`、`core/event_delivery.submit`。
领域术语以根目录 CONTEXT.md 为准（检测≠事件，轨迹≠身份）。

### 代码亮点（值得保留的设计）
- 契约 frozen dataclass + `__post_init__` 校验 + from_dict/to_dict 序列化对称
- 强制时区（无 tzinfo 直接 raise）；用真实时间戳而非帧数计时
- 幂等：event_id 由 `camera:epoch:zone:track:entered_at` 确定性 uuid5 派生；idempotency_key = event_id:revision
- `finalize` 收口：断流/回放结束不留悬挂 OPEN 事件，并清理已闭状态防内存泄漏
- 源周期隔离：track 不跨 epoch，SimpleIoUTracker 切 epoch 时显式返回 expired keys
- 乱序防护：sequence 非单调直接丢弃
- 迟滞阈值：fight start 0.75 / end 0.35，中间带既不确认也不清除
- Outbox：INSERT OR IGNORE 幂等入队 + 分块 flush + 失败留未投递可重试
- 平台/运行时全靠 adapter 隔离：Paddle / Torch / ONNX 同一 FightClassifier interface；EasyAIoT / JSONL 同一 Destination interface
