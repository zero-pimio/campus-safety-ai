# 非法闯入事件规格 v1

- 参与目标：`person`。
- 类别隔离：只有 `target_label` 对应的检测进入该规则的跟踪器，防止不做类别门控的跟踪实现把车等非目标接续为人员轨迹；低置信度目标仍可供跟踪关联，事件可信门限在规则层独立判断。
- 区域判定：原图目标框底部中心点进入归一化多边形；边和顶点包含在区域内，归一化坐标的边界浮点容差为 `1e-12`。
- 开始：目标以不低于 `minimum_confidence` 的可信观测在禁区内持续 `enter_seconds` 后发出 `START`。漏检、低置信度和缺失观测立即打断尚未确认的进入计时；重新观察到目标时重新计时。
- 连续性：相邻可信观测间隔不得超过 `max_observation_gap_seconds`，默认 `2.0` 秒。即使注入的跟踪器保留同一 ID，也不能把超过该间隔的空白时间累计成持续进入。
- 结束：已打开事件的目标被连续观察到离开禁区达 `exit_seconds` 后发出 `END`；漏检和低置信度不等于已确认离开，会重置离开计时。距离最后可信观测超过最大间隔时，打开的事件以置信度 `0` 收口，保留原事件 ID 并增加 revision；若没有新帧到达，必须由入口在断流或超时后调用 `finalize` 收口。
- 去重：同一事件每个 revision 使用唯一 `idempotencyKey`；重复提交不会重复入队。
- 冷却：事件结束后，同一轨迹在 `cooldown_seconds` 内不再次开始。
- 收口：视频源周期结束（断流、回放播完、重启）时，已打开事件通过 `finalize` 发出终版 `END`；回放入口默认在输入结束后调用。跟踪器判定轨迹消失时，打开的事件同样立即补发 `END`。源切换会主动关闭旧源事件，记录中的 camera ID 保持旧源身份；随后清除该源的轨迹状态、序号和时间记录。仅为每个摄像头保留一个最新 epoch 水位，拒绝迟到的旧 epoch 或已结束 epoch，不按历史 epoch 累积记录。
- 时间：全部基于带时区的采集时间戳，不用帧数估算。同一 epoch 内序号必须递增，重复或较旧序号忽略；较新序号的时间戳不得回退，相等时间允许但不增加持续时间。`finalize` 时间不得早于最后接受的观测。新 epoch 可重置采集时间，旧事件结束时间仍不得早于其最后观测。
- 实例隔离：一个分析器和跟踪器同一时刻处理一个源；多摄像头应分别创建实例。切换摄像头不表示跨摄像头延续轨迹。
- 参数：进入、离开、冷却和最大观测间隔必须有限且非负，置信度在 `[0,1]` 内；多边形至少三个点、坐标有限且归一化，并具有非零面积。
- 证据：首版尚未实现截图/短录像；G3 接入时为开始前 5 秒、开始后 10 秒和首张清晰截图。
- 困难负样本：贴边经过、短暂探入、海报/反光、遮挡后重现、低置信度误检。
- 暂不支持：跨摄像头追踪、白名单身份、移动机位。
