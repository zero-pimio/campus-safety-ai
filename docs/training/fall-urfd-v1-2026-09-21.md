# URFD 跌倒分类训练与可行性检查（2026-09-21）

本轮完成了两组真实监督训练，产出独立跌倒/非跌倒权重、ONNX 和实际素材回放。预留测试集 14 段全部分类正确，但验证集仅重复首帧仍能区分全部原始标签，存在明显的静态线索风险。**这版定位为离线研究基线，尚未证明学会跌倒动态，不作为实时告警模型交付。**

## 实际训练了什么

- 数据：[UR Fall Detection Dataset 官方页](https://fenix.ur.edu.pl/mkepski/ds/uf.html)。70 个原始序列，30 个 fall、40 个 ADL；统一使用 cam0 RGB，因为 ADL 没有对应的 cam1 数据。
- 按类别稳定排序后分别使用 `Random(20260921)` 打乱，固定 42 train、14 val、14 test；各 split 的非跌倒/跌倒数量为 24/18、8/6、8/6。同一序列不跨集合；官方未提供可用于本划分的 actor ID，不能宣称跨人物独立评估。
- 每序列从 RGB 帧号与官方同步记录的交集中取 16 个等分中心帧，共 1,120 张实际输入。缓存保存 ZIP CRC、PNG SHA256、源 URL、原始帧号及官方毫秒时间；未下载完整 4.49 GB ZIP，数据缓存约 413.7 MB。
- 原 `adl-37` 有 350 张 RGB，但同步 CSV 只有 330 行。统一交集规则明确排除 331–350 帧，其余 69 段原采样不变；没有猜测帧率或填造时间。该修正在模型训练及选模前完成，记录在 manifest 和 protocol。
- fall/ADL 原始序列类别作为二分类标签，未把官方深度特征 CSV 的“躺地”姿态标签当作跌倒事件标签。
- ImageNet MobileNetV3-Small 图像骨干保持冻结；逐帧 576 维特征计算时间均值、最大值、末帧减首帧，得到 1,728 维。仅用 42 个训练序列拟合均值/标准差，再监督训练线性分类层的 **3,458 个参数**。这不是从零训练视觉骨干。

数据采用 CC BY-NC-SA 4.0。作者要求引用：Bogdan Kwolek、Michal Kepski，*Human fall detection on embedded platform using depth maps and wireless accelerometer*，Computer Methods and Programs in Biomedicine 117(3)，2014，489–501。官方许可页快照随缓存保存。

## 两组实验及最终评估

两组共享相同初始化、训练集标准化器与 seed。AdamW 学习率均为 0.003，整批训练，类别加权交叉熵，最多 200 epoch，验证损失 30 轮无改善早停。先按验证损失选 epoch，再按阈值 0.5 的验证 balanced accuracy、F1、较低损失选模型；只对胜者选择验证阈值。

| Weight decay | 实际 epoch | 选中 epoch | 验证 loss | 验证 F1 | 分类层相对初始化 L2 变化 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 0.01 | 200 | 200 | 0.002012 | 1.0000 | 1.143378 |
| 0.1 | 96 | 66 | 0.002192 | 1.0000 | 1.128907 |

选中 `weight_decay=0.01、epoch=200`，冻结阈值为 `0.5`。两组每个分类层参数均发生变化；独立审计确认最终骨干的全部 240 个状态张量与缓存 ImageNet 权重一致，标准化参数与仅用训练集重算的结果逐元素相等。

冻结 checkpoint、manifest、验证报告和选择规则后，先完成权重重载与 ONNX 检查，再对 test 运行一次预测；后续只读核对已保存分数，没有重复 test 推理或用 test 调参。

样本很少。仅在序列近似独立的假设下，test Accuracy 的 Wilson 95% 区间为 78.47%–100%，Recall 为 60.97%–100%；这不是跨人物或校园人群的泛化置信区间。

## 高分的关键限制

回放显示预定的跌倒验证素材为办公室，日常活动素材为家庭房间，因而追加了验证集静态线索检查。诊断只使用已缓存的 14 个 val 特征，不改变选模、阈值或测试结果。

| 验证输入对照 | 与原始序列标签一致 |
| --- | ---: |
| 原始 16 帧 | 14/14 |
| 仅首帧重复 16 次 | 14/14 |
| 仅末帧重复 16 次 | 14/14 |
| 16 帧倒序 | 13/14 |

变换后的输入没有新的事件真值，上表是与原始标签的对照一致率，不是新的动作识别准确率。结果说明这些验证样本不依赖完整跌倒动态也能被分开，可能涉及静态场景、人物外观或起始姿态；不能仅凭此确定唯一原因是背景。

下一轮优先补足**同一场景、相同人员下的跌倒与易混淆负例**，覆盖正常坐下、蹲下、弯腰、系鞋带及主动躺卧，并按人员/场景隔离评估。随后比较人物裁剪或姿态、运动特征模型。当前整段视频采样包含后续画面，不提供跌倒起始时刻、逐人定位、实时提前量或误报每小时指标；这些仍需连续录像和事件标注。
