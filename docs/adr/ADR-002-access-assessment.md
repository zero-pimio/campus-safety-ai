# ADR-002：通行判定独立持久化，EventRecord v1 只承载告警生命周期

状态：设计采用，待实现。日期：2026-09-23。

## 背景

车辆闯道闸与人员闯门禁必须联合视频、授权容量、时钟和日志完整性作判断。授权可能迟到，事件关闭以后判断也可能更正。现有 EventRecord 序列化固定字段，Outbox 严格版本链拒绝 END 后追加；EasyAIoT mapper 不透传任意字段，并可能将非媒体证据 URI 当作图片。

## 决策

使用独立、严格版本化的 PassageAssessment 记录每次通行及不可变判定版本，由 AccessStore 原子保存授权消耗、判定与待交付事件 spool。现有 EventRecord v1 只投影正式事件的 START/UPDATE/END，按 eventId/revision 关联判定版本。spool 幂等转交现有 Outbox，不要求跨两个数据库的伪原子事务。

结束后的新证据只追加判定版本；平台更正需要独立且显式支持的协议，当前不自动撤回旧平台告警。平台投递载荷必须绑定不可变判定版本，重试不读取 latest 改写同一幂等键。

## 取舍

接受多一份审计契约和本地持久转交桥，以保留已有打架、跌倒、入侵、违停链路的兼容性。放弃把授权塞进 confidence/status、在 END 后 UPDATE 或临时新增 RETRACT 阶段：这些做法会丢语义或违反既有生命周期。未来若正式升级平台契约，应新增版本和兼容测试，而非默许 v1 字典的额外键透传。
