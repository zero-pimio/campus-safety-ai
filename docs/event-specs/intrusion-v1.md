# 非法闯入事件规格 v1

- 参与目标：`person`。
- 区域判定：原图目标框底部中心点进入归一化多边形。
- 开始：目标在禁区内持续 `enter_seconds` 后发出 `START`。
- 结束：已打开事件的目标离开禁区持续 `exit_seconds` 后发出 `END`。
- 去重：同一事件每个 revision 使用唯一 `idempotencyKey`；重复提交不会重复入队。
- 冷却：事件结束后，同一轨迹在 `cooldown_seconds` 内不再次开始。
- 时间：全部基于带时区的采集时间戳，不用帧数估算。
- 证据：首版尚未实现截图/短录像；G3 接入时为开始前 5 秒、开始后 10 秒和首张清晰截图。
- 困难负样本：贴边经过、短暂探入、海报/反光、遮挡后重现、低置信度误检。
- 暂不支持：跨摄像头追踪、白名单身份、移动机位、摄像头断开时对失踪轨迹自动补发 END。
